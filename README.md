# 京东物流官网首页复刻

基于京东物流官网首页的导航、首屏、快捷查询、物流服务、行业解决方案、物流网络、新闻和页脚制作的静态演示页面。

## 运行

直接在浏览器打开 **index.html** 即可；页面使用原生 HTML、CSS 和 JavaScript，无需安装依赖。

## 交互

- 导航菜单支持桌面悬停与移动端展开。
- 首屏轮播可手动切换，也会自动播放。
- 运单查询会将输入的单号带到京东物流官网查询页。
- 物流服务及行业方案标签可切换；新闻卡片、快捷入口与页脚链接会打开对应的官网页面。
- 适配桌面与移动端。

图片与品牌标识来自京东物流官网公开页面，项目仅用于页面复刻展示。查询、登录、下单等实际业务由官网处理。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个 Public 仓库。
2. 将本目录中的全部文件和 assets、.github 两个目录上传到仓库根目录。
3. 推送到 main 分支后，.github/workflows/pages.yml 会自动发布。首次发布若提示未启用 Pages，在仓库的 Settings → Pages → Build and deployment 中选择 GitHub Actions。
4. 发布完成后，在 Actions 工作流详情或 Settings → Pages 中打开公开网址。
